# Horta do Chico

> Concurso Agrinho 2026 — Subcategoria 3: Programação Front-End

Acesse o projeto: https://jhonatangabrielalves-cell.github.io/Horta-do-Chico/

Sobre o Projeto

O **Horta do Chico** é um site desenvolvido para apresentar, de forma simples e intuitiva, informações sobre produtos agrícolas de um produtor rural de Assis Chateaubriand, Paraná.

O projeto busca aproximar as pessoas do campo, mostrando alimentos produzidos por agricultores locais e incentivando a valorização da produção rural. A relação com o tema **"Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente"** está na conscientização sobre a origem dos alimentos, a importância de práticas agrícolas responsáveis e o papel da agricultura no desenvolvimento sustentável — promovendo o equilíbrio entre produção de alimentos, preservação ambiental e qualidade de vida.

Tecnologias Utilizadas

- HTML5 — estrutura semântica das páginas
- CSS3 — estilização, responsividade com Media Queries e animações
- JavaScript — manipulação do DOM, integração com banco de dados em tempo real e interações com o usuário
- Google Fonts — tipografia (Playfair Display, Nunito, Caveat)
- Canva — criação da caricatura do produtor

Funcionalidades

Página Pública ('index.html')
- Hero — apresentação do site com chamada para ação
- Sobre — história e perfil do produtor Chico
- Produtos — vitrine dos produtos cadastrados, carregados em tempo real do banco de dados, com busca por nome e filtros por categoria (Maço, Unidade, Bandeja, Pacote, Kg)
- Contato — links diretos para WhatsApp e telefone do produtor
- Feira — informações sobre localização e horário de atendimento
- Navegação suave com animação entre seções e reset automático de filtros ao trocar de seção
- Layout totalmente responsivo para celulares, tablets e desktops

Painel Administrativo ('admin.html')
O site conta com um painel administrativo protegido por autenticação, destinado exclusivamente ao produtor. Por meio dele é possível:
- Visualizar todos os produtos cadastrados em uma tabela organizada
- Adicionar, editar e excluir produtos
- Controlar a disponibilidade e visibilidade de cada produto no site
- Acompanhar estatísticas rápidas (total, disponíveis, indisponíveis e ocultos)
- Filtrar e buscar produtos por nome ou status

> O painel administrativo é de acesso restrito e não está disponível para uso público.

Como Navegar no Site

1. Acesse o link: https://jhonatangabrielalves-cell.github.io/Horta-do-Chico/
2. Use o menu superior para navegar entre as seções: Sobre, Produtos, Contato e Feira
3. Na seção Produtos, utilize a barra de busca para encontrar um produto pelo nome
4. Use os botões de filtro para ver produtos por categoria
5. Na seção Contato, clique nos cards para abrir o WhatsApp ou realizar uma ligação diretamente
